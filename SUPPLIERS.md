# Supplier research — 90 × 180cm black custom towel

Goal: source a black, 90 × 180cm towel with a custom printed/woven "BIG ASS TOWELS"
wordmark. Findings below are from live web research (Sept 2026); verify current
pricing/MOQ directly with each supplier before ordering.

## Recommended path

**Phase 1 — sampling / low volume:** use a no-MOQ custom printer to validate the
design and get physical samples before committing to a bulk run.

**Phase 2 — production run:** move to a bulk private-label mill once the design is
locked, for materially better unit economics at 300+ pieces.

## Candidates

### 1. Contrado — sampling / no-MOQ custom print
- https://www.contrado.com/custom-beach-towels
- No minimum order quantity — good for producing 1–20 sample/launch units.
- Custom size and full-bleed dye-sublimation printing supported, so a true
  90 × 180cm black towel with an edge-to-edge wordmark print is achievable.
- Best for: initial samples, low-volume/pre-order drops, testing the design
  before a bulk commitment.

### 2. Sale Turkish Towels (saleturkishtowels.com) — bulk private label
- https://saleturkishtowels.com/us-private-label-towel-manufacturer/
- https://saleturkishtowels.com/beach-towel-manufacturer/
- Denizli, Turkey — velour / terry / jacquard beach towels, private label & OEM.
- MOQ: ~300 pieces per design/color (better pricing structure at 500+).
- Lead time: ~3–4 weeks after sample approval.
- Payment: typically 50% deposit → production → balance before shipment.
- Custom black dye + woven or printed logo supported. This is the strongest
  candidate for a production run once the design is finalized.
- To quote: send them the towel spec (90 × 180cm, 600GSM, jet black, wordmark
  placement/print method), target quantity, and target market.

### 3. Towelmed (towelmed.com) — alternate Turkish OEKO-TEX manufacturer
- https://towelmed.com/en/2-promotional-textiles-turkish-towels-manufacture
- Denizli-based, OEKO-TEX certified cotton and microfiber towels, custom
  woven or printed designs, promotional/advertising textile focus.
- Good second-quote source to benchmark pricing/lead time against Sale
  Turkish Towels.

### 4. Cotton Beach Towel / beachtowelcn.com — China, OEM/ODM, stock 90×180 size
- https://cottonbeachtowel.com/promotional-beach-towels/
- https://www.beachtowelcn.com/product/product-oversized-microfiber-beach-towel-90x180/
- Already lists an **oversized 90 × 180cm** microfiber towel as a stock product
  with custom sublimation printing — useful reference for spec/costing, and a
  fast option if a microfiber (rather than cotton terry) hand-feel is acceptable.
- OEM/ODM services for custom colorway (black) and branding.

### 5. Print-on-demand (Printful / Printify) — not recommended for this spec
- Both offer beach towel printing, but their catalog sizes are standard
  ~76 × 152cm (30 × 60in) beach towels, not a true 90 × 180cm cut, and color
  base stock is typically white (dye-sub print, not a black textile). Keep as
  a fallback only if a bulk supplier falls through — the exact size and true
  black fabric spec won't be met this way.

## Suggested spec to send suppliers

| Spec | Value |
|---|---|
| Finished size | 90cm × 180cm |
| Fabric | 100% combed cotton terry, 600GSM |
| Color | Jet black (reactive dye) |
| Branding | "BIG ASS TOWELS" wordmark, screen print or woven jacquard, white/off-white ink |
| Edge finish | Fringed short ends (90cm sides) |
| Packaging | Individual poly bag + hang tag |
| Target MOQ (launch) | 25–50 units (sample/Contrado) → 300+ units (Turkish mill) |
